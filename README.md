# Promo Studio

Professional promotional video editor for Android (Flutter) and Web (Next.js).

## UI starter

Download `Promo-Studio-UI-Starter.zip` from the repository and extract it. It contains the initial white + mint-green UI for the website and Android app.

## Current milestone

UI-first starter only. Supabase authentication, Cloudflare R2 uploads, real timeline editing, rendering/export, and ads are not connected yet.

## Security

Do not commit API secrets. Use `.env.example` as a template. Keep Supabase service-role keys and Cloudflare R2 credentials on a trusted server only.
